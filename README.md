# VisitMade

VisitMade's marketing website: destination websites, CRM, membership management and reporting in one connected package.

## Development and deployment

No runtime dependencies. Run `npm run check` and `npm run build`. Deploy the resulting `dist/` directory as a static site. For Vercel, import this repository, select Other, set the build command to `npm run build` and output directory to `dist`.

## Content and brand

- Uses the approved original violet-concept lettering recoloured dark green and teal. `assets/visitmade-brand.png` is the original artwork; CSS frames the wordmark without altering it.
- Product copy is based on `DTosh44/visit-crm` README and implemented Dashboard, Insights, navigation and agreement features inspected on 22 September 2026.
- Product UI examples on this page are illustrative, not screenshots or customer results.
- Existing Visit Valechester demo imagery is reused from the source repository. The destination and its imagery are illustrative.
- Public website and CRM demo links point to `https://visit-crm.vercel.app/` and `/crm`.
- Third-party services and supplied-data reporting are described with their configuration requirements. No unverified customer testimonials, performance promises, live integrations, pricing or compliance certification are claimed.
- No analytics or enquiry form is enabled. Add the agreed sales contact/booking destination when available; do not invent one.

## Interaction and accessibility

Responsive navigation, keyboard-operable product tabs, native FAQ disclosures, visible focus, reduced-motion support, descriptive links and semantic document structure. These measures do not constitute a full accessibility audit or certification.
